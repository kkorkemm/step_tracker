# Трекер шагов с друзьями - FootCrew
Команда 11: Жардемова Коркем, Искакова Амина, Барабан Алексей, Богуславский Антон

## Стек технологий

- **Flutter** (Dart) — кроссплатформенная разработка
- **Provider** — управление состоянием (MVVM)
- **Hive** — локальное хранение данных
- **Pedometer** — доступ к шагомеру телефона
- **Permission Handler** — управление разрешениями

## Ключевой сценарий: Получение трекера активности за сегодняшний день. 
Пользователь открывает Главный экран приложения. Система берет данные с шагомера (pedometer) и c локальной БД и возвращает трекер с прогрессом, стрик (кол-во дней с выполненной нормой подряд) и активный челлендж пользователя, если такой есть.

В прототипе:
- Главный экран с круговым прогрессом шагов, количеством шагов (из моков или реальные), дистанцией, калориями, часами активности, текущим стриком (серией дней)
- Активный челлендж отображается внизу (берётся заготовленный тестовый)
- Тестовые кнопки:
  - "+1000" — добавить шаги (тестирование отображения кругового прогресса и заполнения шкалы в активном челлендже)
  - "Сброс" — сбросить шаги за сегодняе
  - "Создать тестовый челлендж" — создать мок-челлендж
- Обработка состояний:
  - loading — индикатор загрузки при старте
  - normal — основной режим с данными
  - empty — сообщение, если нет челленджа
  - error — сообщение об ошибке с кнопкой повтора

## Мок-данные
Для тестирования без реального шагомера используются мок-данные.
Переключение между моками и реальными данными в ```lib/main.dart```:
```
const bool USE_MOCKS = true; // true - моки, false - реальные данные
```
Мок-данные находятся в:
- ```lib/data/mocks/mock_data.dart``` — сами данные
- ```lib/data/repositories/mock_challenge_repository.dart``` и ```lib/data/repositories/mock_tracker_repository.dart``` — мок-репозитории
